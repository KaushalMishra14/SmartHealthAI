SmartHealthAI -

An AI-powered medical recommendation system that predicts diseases from symptoms and provides remedies, health guidance, and prediction history tracking.

Features :

Disease prediction using TensorFlow model,
Symptom-based diagnosis,
Home remedies and Ayurvedic suggestions,
AI health chatbot powered by Gemini,
User authentication (JWT),
Personal prediction history tracking,
MongoDB Atlas database,
Responsive React frontend


Tech Stack :

Frontend-
* React.js
* Vite
* Tailwind CSS
* Axios

Backend-
* Node.js
* Express.js
* JWT Authentication
* MongoDB Atlas

Machine Learning-
* Python
* Flask
* TensorFlow / Keras
* NumPy
* Pandas

Deployment :

Frontend- Vercel
Backend- Render
ML API- Hugging Face Spaces
Database- MongoDB Atlas

Project Structure:

SmartHealthAI/

─ client/       # React Frontend
─ server/       # Node Backend
─ ml-api/       # Flask ML API

How It Works:

1. User selects symptoms.
2. React frontend sends request to backend.
3. Backend forwards symptoms to ML API.
4. TensorFlow model predicts disease.
5. Backend stores history in MongoDB.
6. Results are shown to the user.
